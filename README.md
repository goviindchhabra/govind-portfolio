   Cloud Deployment

This portfolio demonstrates the use of GitHub Pages as a cloud-based hosting service.

Deployment Process

Created a GitHub repository named govind-portfolio.

Added the HTML, CSS, JavaScript, and README files.

Committed the files to the main branch.

Opened Repository → Settings → Pages.

Selected Deploy from a branch.

Selected the main branch and / (root) folder.

Saved the configuration.

GitHub Pages automatically built and hosted the website.
